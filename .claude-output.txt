`★ Insight ─────────────────────────────────────`
- The `fetch('/api/config')` runs immediately (no `DOMContentLoaded` wait needed) because the `<script>` tag is at the bottom of `<body>` — all DOM nodes are already parsed when JS executes
- CSS `env(safe-area-inset-bottom)` is a CSS environment variable specific to iOS notch/home-bar devices — `max(20px, env(..., 20px))` ensures minimum 20px on non-notched devices while respecting the safe area on notched ones
- The `--tool-color` CSS custom property approach means the entire accent theme changes with one `setProperty` call — this is more maintainable than updating multiple element styles individually
