`★ Insight ─────────────────────────────────────`
The blockquote implementation used a `currentBlockquote` state variable that mirrors the existing `currentList` pattern — this is the most maintainable approach in a line-by-line parser. The key insight is that blank lines must reset the grouping state (`currentBlockquote = null`) at the same point where other block elements are reset, preventing consecutive blockquotes from incorrectly merging across paragraphs.
